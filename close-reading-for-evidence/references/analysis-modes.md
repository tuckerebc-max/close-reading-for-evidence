# Analysis modes

Select only modes supported by the supplied source and task.

| Mode | Inspect | Do not claim without evidence |
|---|---|---|
| Literary | diction, imagery, structure, voice, perspective, pattern | author intent or universal meaning |
| Informational or technical | claim, organization, definition, data, figure, qualification | accuracy beyond the supplied source |
| Legal or policy | stated rule, authority, reasoning, scope, uncertainty | current legal effect or advice |
| Research | question, method, evidence, limitations, implications | findings not present in the source |
| Multimodal | text/visual relationship, locator, design choice, accessibility | meaning from an inaccessible feature |
| Comparative | agreement, contradiction, context, source role, missingness | consensus from majority count |

Use separate locators for text, graph, figure, timestamp, panel, or other modality. Mark a requested mode `NOT_APPLICABLE` when the source does not support it.
